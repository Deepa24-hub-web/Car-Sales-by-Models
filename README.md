#  Car Sales Analysis Dashboard (Microsoft Excel)

## Project Overview

This project demonstrates how Microsoft Excel can be used to transform raw sales data into actionable business insights through data analysis, PivotTables, PivotCharts, and interactive dashboards.

Using a dataset of **1,200+ car sales records**, I analyzed sales performance across multiple dealers, vehicle models, and time periods to identify trends in profitability and sales performance.

## Objectives

* Analyze sales and profit by dealer and vehicle model.
* Track monthly profit trends over two years (2018–2019).
* Identify top-performing dealers based on quantity sold and profit.
* Build an interactive dashboard for business reporting and decision-making.

## Key Analysis Performed

### 1. Top Dealers by Quantity Sold

Created a PivotTable to identify the highest-performing dealers based on total vehicles sold.

### 2. Monthly Profit Analysis

Analyzed monthly profit across five vehicle models to understand seasonal trends and compare model performance between 2018 and 2019.

### 3. Dealer Profit Comparison

Compared annual profit generated by each dealer, enabling quick identification of the strongest-performing dealerships.

### 4. Model-Specific Profit Analysis

Performed detailed profit analysis for the **Hudson** model across all dealers to evaluate dealer-level performance for a single product.
